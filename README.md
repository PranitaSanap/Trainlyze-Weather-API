# TRAINLYZE Weather API Project

## Project Description
This project is a Python-based Weather Information System developed using the OpenWeather API.

It fetches live weather information for a city entered by the user.

## Features
- Search weather by city name.
- Display temperature in Celsius.
- Display feels-like temperature.
- Display humidity.
- Display wind speed.
- Display weather conditions.
- Handle invalid city names.
- Handle internet connection errors.

## Technologies Used
- Python
- OpenWeather API
- Requests Library
- JSON

## Installation
Install dependencies:

`pip install -r requirements.txt`

## How to Run
Execute:

`python main.py`

Enter a city name to view its weather information.
